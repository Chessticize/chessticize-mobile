Accessibility

What the current app supports

Chessticize does not currently declare support for any App Store accessibility feature. Some surrounding controls have useful labels, but the puzzle board does not provide a complete accessible move-entry path, and not every common chess puzzle task has been verified.

Broad remediation is not currently scheduled. The related issue records are closed as not planned; that status does not change the current app or complete any pending verification.

Screen readers and voice

Menus, tabs, buttons, and many status updates have useful labels. The puzzle board itself does not yet provide a complete VoiceOver or Voice Control move-entry path, so those features are not declared in the App Store.

Text and appearance

Very large system text can clip or overlap controls, and the app does not yet provide a complete dark interface. Larger Text and Dark Interface are therefore not declared.

Visual and motion checks

Verified contrast failures remain, some Settings controls are smaller than the 44pt target, and the app does not follow Reduce Motion. No color-only blocker has been confirmed, but the complete grayscale common-task walkthrough is still pending. These features remain undeclared.

Orientation and iPad

iPhone uses portrait. iPad supports portrait and landscape, with landscape as the primary large-screen layout. Large-text fixes are still required in both size classes.

How we prioritize accessibility work

Verified board, text, contrast, touch-target, motion, and dark-interface limitations remain in the current app. The grayscale check is different: no color-only blocker has been confirmed, but the complete walkthrough is not recorded.

Chessticize does not collect usage analytics. A report that names the puzzle flow, device, and assistive setting provides concrete context if this scope is reconsidered.

Share accessibility feedback

Include the puzzle flow, device, and assistive setting you used. Public reports can be tracked on GitHub; private questions can go to support.
