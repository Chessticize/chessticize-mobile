Hi everyone! I've been using the offline app myself lately and figured nobody was using the website anymore, so I was about to shut it down. Then I checked and was so happy to find some of you actually use it. Thank you so much for using it, and sorry about the sudden outage!

It's now at app.chessticize.com, and I'll keep it maintained and updated as best I can. Found a bug or want a feature? Come chat in the chessticize-web Discussions.

Chessticize is a one-person hobby project, so please bear with the rough edges. The mobile app on this page works completely offline, give it a try too.
