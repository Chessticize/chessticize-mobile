## Customer-facing changes

- Keep Practice, History paging, Review queues, and new Run startup responsive with large puzzle histories.
- Preserve exact History summaries while reducing repeated full-history work and bounding chart rendering.
- Show Arrow Duel boards before their choice arrows and keep two-digit Review counts fully readable.

Chessticize 1.2.1 is a bug-fix release centered on keeping Practice, History,
Review, and new Run startup responsive for players with large puzzle histories.
It also fixes Arrow Duel board/arrow presentation order and truncated
two-digit Review counts. This release adds no new features.
