# Chessticize Android 1.7.0 (build 26)

- Status: Approved
- Locale: `en-US` (with localized store copy for `zh-CN`, `zh-TW`, `ja-JP`, `ko-KR`, `es-ES`, `de-DE`, `fr-FR`, `pt-BR`)
- Platform: `Android`
- Public version: `1.7.0`
- Build or version code: `26`
- Source tag: `android-v1.7.0-build-26`
- Previous public source tag: `android-v1.6.3-build-25`

## Customer-facing changes

- Added full app localization for 9 languages (`English`, `简体中文`, `繁體中文`, `日本語`, `한국어`, `Español`, `Deutsch`, `Français`, and `Português (Brasil)`) with an in-app language picker at the top of Settings, localized Android notification channels, and preserved regional date and number formatting.
- Added customizable Lichess-inspired board color schemes (with independent Light and Dark mode selections) and classic chess piece sets under Settings → Appearance.
- Reorganized Settings by frequency and added a localized Third-Party Notices link in Settings → About covering chess piece sets, audio, icons, and open-source libraries.
